# Changelog

## [0.1.0] - 2025-09-11

### Added
- Initial release of the `vg-anchor` tool.
- `build` command to create an anchor dictionary from a variation graph and distance index.
- `get-anchors` command to generate anchors from GAF alignments.
- Core greedy algorithm for extending heterozygous and homozygous anchors and snarl merging based on read support
- Project `LICENSE` and `README.md` files.
